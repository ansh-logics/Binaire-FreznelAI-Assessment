# Movies

Hi, I am Ansh Bhatt. This is my submission for the Freznel AI Web Store UI assessment.

The reference UI was from Steam but the required data was from TMDB, so I used the reference for the layout and interactions and converted it into a movie discovery website.

The app has movie discovery, search, genre filtering, carousel, lazy loading, pagination, movie details, Firebase authentication, My List and offline cached data.
